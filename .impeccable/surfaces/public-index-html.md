## Direction contract

THESIS: Replace KPV's amber brand chrome with a committed deep-maroon (`#990000`) identity, inspired by a reference Thai "beauty recap" app's airy, blush-toned mood — refusing the app's current flat-amber, violet-tinted-canvas default.

OWN-WORLD: Brand ramp built on HSL(0°, 100%, L) anchored at `brand-600 = #990000` (50 `#ffebeb` → 900 `#420000`); canvas shifts from `#faf8ff` to blush-white `#fdf4f3`; danger pushed to a text-safe vermillion `#c0330c` (fill `#ee552b`, bg `#fdf0ed`) so it reads as clearly distinct from brand maroon and from warning amber, never relying on hue alone — status pills keep pairing color with text/icon. Literal "Gold Bars" categorical chart color stays amber (material truth, not brand chrome); success/warning tokens untouched. Typography stays Plus Jakarta Sans / Noto Sans Lao.

STORY: An owner opens Dashboard and reads the hero portfolio-value card — a confident maroon-to-deep-maroon gradient block with one bold white number — then scans list/ledger rows (label-left, tabular-numeral-right) and status pills that stay legible against the new blush ground. A cashier mid-settlement sees the same fast, 44px-target forms, just recolored.

FIRST VIEWPORT: Dashboard — sticky topbar on blush canvas, hero stat card (maroon→deep-maroon gradient, bold white numeral + label, white status pill), movement/watchlist/aging cards in white with maroon-token accents below, bottom nav with maroon active state.

FORM: User-pinned direction (5 reference screenshots of a Thai lifestyle app + explicit brand hex `#990000`, confirmed via structured Q&A on scope/color-replacement-strategy/danger-collision/motion-level). concept-seed roll not run — a pinned direction supersedes it. seed: none (user-pinned, no roll).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
